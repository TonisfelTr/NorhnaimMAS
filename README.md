# Профиль пациента v1 — Норхнейм

Пакет рассчитан на установленную панель пациента v1 и ветку
`fix/filament-fix-parameters`.

## Добавлено

- отдельный профиль пациента в `/patient/profile`;
- редактирование ФИО, даты рождения, пола, места рождения;
- контактный телефон и контактный email;
- адрес регистрации и адрес проживания;
- фотография профиля через существующее поле `users.avatar`;
- смена пароля с проверкой текущего пароля;
- просмотр удостоверяющих документов (номер маскируется);
- история изменений личных данных;
- отдельная запись аудита изменений;
- пункт «Мой профиль» в боковом меню пациента.

## Что пациент не может менять

Не открыты для самостоятельного редактирования:

- диагноз и клинические сведения;
- рост, вес и инвалидность;
- лечащий врач и клиника;
- СНИЛС и полис ОМС;
- реквизиты удостоверяющих документов.

Для изменения удостоверяющих документов пациент обращается в регистратуру:
эти сведения должны быть проверены клиникой.

Email в поле «Контактный email» хранится в `patients.email` и не меняет
адрес входа `users.email`. Изменение email для входа требует отдельного
механизма подтверждения.
